## Motivation

QP1 computes parity-dependent total-spin multiplets in finite spin-1 chains. QP2 calculates site-resolved spin and longitudinal string correlations. Neither result, by itself, establishes the thermodynamic Haldane phase or distinguishes its physics from every possible alternative.

**QP3 changes exactly one defined physical-model term while retaining the rest:**

\`\`\`text
H(J,D) = J Σ_{i=0}^{N-2} S_i · S_(i+1) + D Σ_{i=0}^{N-1} (S_i^z)^2
J = +1 (energy unit)
\`\`\`

The first term is the **unchanged QP1 antiferromagnetic spin-1 chain**. The added single-ion easy-plane anisotropy D is nonnegative. Large positive D suppresses nonzero site m and favors the unentangled |0,0,...,0> state. This is a finite Hamiltonian comparison, not a claim of measuring a materials phase transition.

## Frozen calculation grid

- Chain lengths **N=4,6,8**, open boundary conditions throughout.
- Dimensionless anisotropy values **D/J = 0,1,4,12**.
- Lowest normalized eigenstate in the **total M=0** sector, computed from the QP1 basis with dense/sparse Hermitian diagonalization and a numerical eigenpair residual check.
- The same pair **(i,j)=(0,N−2)** throughout, as in QP2.
- Longitudinal string: \`O_z = -<Sz_i exp(iπΣ_{k=i+1}^{j-1}Sz_k) Sz_j>\`.
- Ordinary two-site control: \`C_z = -<Sz_i Sz_j>\` on the **same sites**.
- Mean quadrupolar occupation: \`<Σ_i(Sz_i)^2>/N\`.
- Reference overlap: \`|<0,0,...,0|ψ>|²\`.
- Ground eigenvalue of the **M=0 sector**, explicitly **not** total-spin S. Adding D breaks the SU(2) symmetry used by QP1's spin inference.

No model is trained, no pretrained weights or AI outputs are involved.

## Acceptance and falsifiers

1. The D=0 rows reproduce the frozen QP2 open-chain string, two-point and M=0 energy values within 1e−7.
2. For all three tested sizes, D=12 gives **higher |0...0> overlap and lower <(Sz)^2>** than D=0. A failure must be reported, not adjusted away.
3. All 12 parameter combinations produce normalized eigenvectors with residual norm at most 1e−7, a conserved total M=0, and finite real observables.
4. The source-controlled and browser results must be generated by the same numerical source with no hard-coded chart numbers. A create-only \`write\` command and independent \`verify\` recomputation enforce reproducible **numeric agreement**, not independent attestation.
5. Explicit \`SIMULATED / authority NONE / attested false\` labels appear in both JSON metadata and browser explanations.
6. Preserve QP0–QP2 and E0/E1 original mathematical results.

**This is *not* a complete trivial-phase control:** D=12 is expected to be a high-D product-favoring *comparison regime* of the same model. Demonstrating finite contrast neither determines a critical D nor proves either phase; the all-zero-state overlap is a model statistic, not laboratory fidelity. Finite N=4–8 makes finite-size effects unavoidable.

The static React site consumes \`web/src/data/qp3-reference.json\`. **This file is build-generated, not hand-authored or committed.** GitHub Pages CI first runs the Python calculator with \`PYTHONPATH=src\`, then Node tests and Vite build.
