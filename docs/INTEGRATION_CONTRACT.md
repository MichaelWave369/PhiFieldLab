# Proposed integration boundaries (NOT existing connections)

- **NestedBubbleGear**: read-only, explicit import of separately versioned synthetic protocol data and signed-off experiment definitions. No rewrite of frozen experiments.
- **NBGPocketMesh**: optional later registration of exported model capabilities; v0.1 never invokes its adapters or routes training.
- **PhiStream**: optional future safetensors compatibility adapter, only after architecture support is independently tested. This release does not imply inference interoperability.
- **PhiCleanroom / Anti-M**: future evidence and completion-gate adapters; v0.1 manifest hashes are unauthenticated and cannot assert DONE.
- **SuperPhiVessel**: future opt-in operator-controlled discovery; no automatic model load, permissions, cloud calls, or routing.
- **CFD / Infinite Commons**: optional read-only research display, with mandatory SIMULATED provenance watermark and direct link to raw results.

All integrations are proposals. No external repos are modified, and no actual endpoints are called.
